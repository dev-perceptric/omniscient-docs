An opportunity is a deal with a company. It sits in one pipeline, at one stage, and can have an amount, a close date and an owner.

## The opportunity object

```json
{
  "id": "0b6f3c52-8d1e-4f7a-9c2b-5e4d3a2b1c0d",
  "name": "Lumen Health expansion",
  "account_id": "7c8d9e0f-1a2b-4c3d-8e4f-5a6b7c8d9e0f",
  "pipeline_id": "e1d2c3b4-a5f6-4e7d-8c9b-0a1f2e3d4c5b",
  "stage": "proposal",
  "stage_name": "Proposal",
  "stage_kind": "open",
  "amount": 48000,
  "close_date": "2026-12-15",
  "owner_id": "f0e1d2c3-b4a5-4f6e-8d7c-9b0a1f2e3d4c",
  "fields": { "source": "Referral" },
  "created_at": "2026-10-20T13:02:11+00:00",
  "updated_at": "2026-11-18T10:45:09+00:00"
}
```

| Field | Type | What it is |
| --- | --- | --- |
| `id` | string | The opportunity's id |
| `name` | string | Its name |
| `account_id` | string or null | The company's id |
| `pipeline_id` | string | The pipeline it sits in |
| `stage` | string | The stage's key, like `proposal` |
| `stage_name` | string | The stage's name, like "Proposal" |
| `stage_kind` | string | `open`, `won` or `lost` |
| `amount` | number or null | Its value |
| `close_date` | string or null | `YYYY-MM-DD` |
| `owner_id` | string or null | The owner's user id. See [GET /owners](/api-reference/owners/). |
| `fields` | object | Every custom field value, by key |
| `created_at` | string | When it was opened |
| `updated_at` | string | When it last changed |

## GET /opportunities

Lists opportunities, newest first.

```http
GET https://app.tryomniscient.com/api/v1/opportunities
```

**Scope:** `read`

| Parameter | Type | What it does |
| --- | --- | --- |
| `account_id` | string | Only opportunities at this company |
| `stage` | string | Only opportunities at this stage key, like `proposal` |
| `limit` | number | 1 to 100, default 50 |
| `offset` | number | Rows to skip, default 0 |

```bash
curl "https://app.tryomniscient.com/api/v1/opportunities?stage=proposal&limit=20" \
  -H "Authorization: Bearer omn_your_key"
```

`200 OK`

```json
{
  "data": [
    {
      "id": "0b6f3c52-8d1e-4f7a-9c2b-5e4d3a2b1c0d",
      "name": "Lumen Health expansion",
      "account_id": "7c8d9e0f-1a2b-4c3d-8e4f-5a6b7c8d9e0f",
      "pipeline_id": "e1d2c3b4-a5f6-4e7d-8c9b-0a1f2e3d4c5b",
      "stage": "proposal",
      "stage_name": "Proposal",
      "stage_kind": "open",
      "amount": 48000,
      "close_date": "2026-12-15",
      "owner_id": "f0e1d2c3-b4a5-4f6e-8d7c-9b0a1f2e3d4c",
      "fields": {},
      "created_at": "2026-10-20T13:02:11+00:00",
      "updated_at": "2026-11-18T10:45:09+00:00"
    }
  ],
  "limit": 20,
  "offset": 0
}
```

The `stage` filter matches the stage key, not the name. The [MCP tool](/api-reference/mcp-tools/#describe_fields) `describe_fields` lists each pipeline's stages with their keys.

## GET /opportunities/:id

Reads one opportunity.

```bash
curl https://app.tryomniscient.com/api/v1/opportunities/0b6f3c52-8d1e-4f7a-9c2b-5e4d3a2b1c0d \
  -H "Authorization: Bearer omn_your_key"
```

`200 OK` with one opportunity object.

## POST /opportunities

Opens a new opportunity. Each call makes a new one, so don't retry a call that timed out without checking first.

```http
POST https://app.tryomniscient.com/api/v1/opportunities
```

**Scope:** `write`

| Field | Type | Required | What it does |
| --- | --- | --- | --- |
| `name` | string | Yes | Up to 200 characters |
| `account_id` | string | No | The company's id |
| `domain` | string | No | Instead of `account_id`: the company's domain. Omniscient makes the company if it's new. |
| `account_name` | string | No | With `domain`: the name for a new company |
| `pipeline` | string | No | The pipeline's id or name. Left out, the default pipeline. |
| `stage` | string | No | The stage's key or name. Left out, the pipeline's first open stage. |
| `amount` | number | No | Send a number, not a string |
| `close_date` | string | No | `YYYY-MM-DD`. Other formats are ignored. |
| `owner_id` | string | No | A team member's user id |
| `owner_email` | string | No | Instead of `owner_id`: a team member's email |

```bash
curl -X POST https://app.tryomniscient.com/api/v1/opportunities \
  -H "Authorization: Bearer omn_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Harbor Bank pilot",
    "domain": "harborbank.example.com",
    "account_name": "Harbor Bank",
    "pipeline": "New business",
    "stage": "Discovery",
    "amount": 12000,
    "close_date": "2027-01-31",
    "owner_email": "jordan@northwind.example.com"
  }'
```

`201 Created` with the opportunity object.

<Aside type="note">
Pipeline and stage names match without regard to case. An owner who isn't in the workspace is left blank, without an error.
</Aside>

## Errors

| Status | `code` | `message` |
| --- | --- | --- |
| 400 | `bad_request` | `name is required` |
| 400 | `bad_request` | `account_id must be an id.` |
| 404 | `not_found` | `account not found` |
| 404 | `not_found` | `pipeline not found` |
| 404 | `not_found` | `stage not found in that pipeline` |
| 404 | `not_found` | `Opportunity not found.` |
| 401 | `unauthorized` | The key is missing or revoked |
| 403 | `forbidden` | `This key can't write.` |
